# CityGo UI 重设计预览索引

日期：2026-10-26。仅设计预览，未修改 App 源代码。

## 范围与依据

已检查 SkeletonApp.kt 导航注册、各 Screen/Dialog/Page 文件、strings.xml 以及项目验收文档。本套图按功能合并和重新安排页面，不是对当前每个路由截图的一比一复刻，也不是全部功能实机通过的保证。主页面沿用第 01 张总览，新增 9 张设计板，共 56 个页面/状态示意位。

旧版或独立实现（如 TravelGuideScreen、TripPlanActivity、WebView 配套网页）的重复能力统一到行程配置与结果；不为相同功能重复设计三套外观。OotdAnalyzeScreen 单图流程作为现有独立实现保留展示，当前 SkeletonApp 导航明确注册的是 StylistScreen，多图入口的实际接线情况以后实施前需确认。

## 页面索引

### 02 发现与景点

- 02-1：城市选择：定位城市重庆，城市搜索支持中文/拼音，热门城市和城市列表
- 02-2：景点搜索：搜索框鹅岭，搜索结果列表，缩略图、城市、类型和收藏图标，无结果提示以角落小注说明
- 02-3：精选筛选半屏弹层：城市推荐/附近精选20公里，类别，已核实免费/允许携宠/有条件携宠，重置和确定。不要将未知政策标成允许
- 02-4：景点详情上半页：大幅鹅岭二厂实景图，返回收藏，名称、地址、简介、开放时间、门票、加入行程和路线按钮
- 02-5：同一景点详情下半页：游玩介绍、交通信息、携宠条件说明、旅行小贴士、查看相关游记，底部仍是加入行程和去导航
- 02-6：加入行程弹层：第1天/第2天/第3天选择，确认添加，已有地点显示已在行程，轻提示添加成功

### 03 AI 行程与编辑

- 03-1：行程配置全屏表单：城市重庆可更换、1至15天选择、人均预算选填、偏好多选美食拍照购物自然风光、优先宠物友好开关、额外备注、生成AI攻略按钮
- 03-2：行程生成状态：正在为你规划重庆，loading不画虚构进度百分比，已提交的3天预算偏好摘要，生成中按钮禁用，错误重试小状态框
- 03-3：已生成行程与操作底部弹层：每日时间线背景，弹层有添加景点、添加酒店、自定义地点、重新配置、清空行程。仅视觉重组已有操作
- 03-4：酒店搜索选择：搜索商圈/地标/酒店名，酒店列表实景缩略图地址、选择加入第2天按钮，没有价格预订支付
- 03-5：补充自定义地点表单弹层：名称、地址、地点类型、所属天数，查找位置/保存，定位失败说明可补充更完整地址，不显示开发参数
- 03-6：AI旅行助手：顶部当前重庆行程上下文，用户消息把第一站换成携宠公园，AI中文回复调整说明、已更新行程提示，输入栏，思考中状态小注，无JSON无供应商名

### 04 地图导航与天气

- 04-1：地图点位与天数筛选：地图为主，全部天数/第1天/第2天选择面板，地点卡片含在行程中查看、从我的位置出发导航，起终点选择
- 04-2：路线规划比较：起点我的位置终点鹅岭二厂可交换，驾车步行骑行公交4方式tab，地图路线，2个候选路线时长距离，查看步骤和开始导航
- 04-3：逐段路线预览：顶部目的地与总里程、地图小预览，下方左转直行等逐段路线列表，距离，底部开始导航
- 04-4：正在导航：原生地图导航示意，顶部下一路口200米右转大箭头，路线与当前位置，底部剩余时间距离、语音开关与退出，独立全屏无底栏
- 04-5：天气总览：城市重庆可切换，24°晴，实时信息，7日天气列表，未来日期占位数据写示例，小时/气象图只展示简洁温度趋势，不发明空气质量能力
- 04-6：单日天气详情：返回天气，周二日期，晴转多云、温度范围、白天夜间风向风力与天气趋势视觉，城市搜索入口。示例天气非实时预报

### 05 社区与内容发布

- 05-1：社区主页：搜索、推荐/携宠旅行/旅行穿搭内容分类，AI穿搭入口，双列实景照片卡片，发布按钮，底栏社区高亮
- 05-2：游记详情上半页：返回作者头像、图片轮播1/4、标题正文、城市，固定底栏评论输入点赞收藏，不画未实现关注私信
- 05-3：游记详情评论区：同一文章滚动到评论，用户头像、评论列表、输入键盘上方发送条，点赞收藏状态，与详情一致
- 05-4：发布游记：多图选择可移除排序视觉，标题、正文编辑，发布按钮和上传中状态示意，不添加未经证实视频发布
- 05-5：我的发布内容库：社区/我的发布/我的收藏切换，自己发布帖子列表图文与日期，点击打开详情，无虚构后台统计
- 05-6：收藏帖子内容库：已收藏游记双列卡片，取消收藏操作底部弹层，空收藏状态作为角落小卡，去逛社区按钮

### 06 两种 AI 穿搭流程

- 06-1：AI穿搭工具入口：两张清晰卡片，单张穿搭分析/结合行程的多图评估，说明照片分析与旅行适配的区别，不发明试衣生成功能
- 06-2：单图OOTD照片选择：大幅上传占位，拍照/相册按钮，想让AI分析什么文本框，开始分析，隐私友好的简短提示无虚构承诺
- 06-3：单图已选照片分析中：女性日常旅行穿搭照片，重新拍照/相册重选，上传中至分析中文字输出状态，禁用重复分析按钮
- 06-4：单图分析结果：原图预览，分段穿搭建议文本，知识库引用可展开标签，分析完成、重新分析按钮，不发明数值评分
- 06-5：多图结合行程评估：3张穿搭照片可删除继续添加，当前行程重庆3天摘要可展开，用户补充问题，提交综合评估
- 06-6：多图综合评估结果：照片1/2/3缩略图、当前行程摘要，中文建议按步行场景/天气/搭配舒适度表达，流式文本区，重新评估，无虚拟换装

### 07 个人资料宠物与日记

- 07-1：我的主页：个人资料、统计、当前城市选择、收藏攻略收藏帖子浏览记录、宠物档案、旅行日记、AI行程穿搭评估入口、设置入口，底栏我的高亮
- 07-2：个人资料展示：头像昵称简介、性别生日地区职业学校和编辑资料按钮，展示内容采用示例，无关注粉丝功能
- 07-3：编辑个人资料：更换头像、昵称、简介、性别、生日、地区、职业、学校，底部保存，头像选择拍照/相册小弹层
- 07-4：宠物档案管理：我的柯基豆包档案卡片，添加宠物入口，编辑弹层含名字品种体重kg与外观头像选择按简洁样式，删除二次确认小框，不发明医疗健康数据
- 07-5：旅行日记列表：标题日期摘要卡片，写日记按钮，条目编辑和删除菜单
- 07-6：写与编辑旅行日记：标题和内容多行编辑，保存取消；底部角落小浮层删除日记确认。保持私人日记与社区发布区别

### 08 收藏设置与占位入口

- 08-1：收藏攻略：实景景点卡片列表，名称城市介绍、点击详情、取消收藏按钮，空态小注
- 08-2：浏览记录：按日期分组景点记录，右上清空，清空确认居中弹窗示例，点景点进入详情
- 08-3：设置主页面：深色主题开关、隐私设置、缓存、存储空间、内容偏好调节、添加小组件、未成年人模式、新功能体验、帮助与客服、关于、切换账号、退出登录。占位项右侧写开发中，信息分组可滚动
- 08-4：隐私设置：个性化推荐、允许陌生人查看我的笔记、允许获取位置信息开关；账号与安全和黑名单管理旁标开发中，说明当前入口为占位
- 08-5：关于我们：CityGo标志、版本示例、用户协议/隐私政策/检查更新，现阶段占位项标开发中，不虚构法律条款内容；下方开发中提示弹窗示例
- 08-6：深色外观与确认弹窗：展示深色我的主页作为主题状态，旁边在同一手机内下半区域排列退出登录/清空行程/删除宠物三种小型确认示意，危险按钮暗红，取消为主要安全操作

### 09 登录账号与通用状态

- 09-1：密码登录：CityGo品牌简约插图，手机号密码、显示密码、密码登录/验证码登录tab、登录、去注册；不要添加未经实现第三方登录
- 09-2：验证码登录：手机号、6位验证码、获取验证码/倒计时、登录按钮，发送中和输入错误小提示
- 09-3：注册：手机号密码验证码按已有注册使用手机号密码为主，创建账号、返回登录，无第三方账号
- 09-4：首次完善资料：头像昵称性别生日等基本资料分组，可滚动保存进入，保持与资料编辑视觉一致，不虚构强制偏好测试
- 09-5：账号中心：当前头像昵称、用户ID、手机号信息，重新加载资料、进入首页，资料加载失败小提示
- 09-6：切换账号：当前账号和已保存账号列表，当前账号标识，添加账号登录、移除本机账号操作及二次确认，清楚与注销账号不同
- 09-7：通用状态上：空行程去规划、搜索无结果调整关键词、网络失败保留内容点重试，三个状态卡示意放在同一手机内
- 09-8：通用状态下：定位权限说明去设置、相机权限未授权提示、AI生成失败重试、发表上传中禁用按钮，四种状态以卡片方式在同一手机内；不画系统权限弹窗伪造界面

## 实施时必须遵守的现状边界

- 社区最新代码已有关注/取消关注作者、本人游记编辑与删除、评论回复与删除，以及公开/仅自己/仅选中的人/不给选中的人看/互关好友可见范围；这些在第 10 板补齐，以最新源代码优先于旧验收文档。
- 单图 OOTD 不自动读取行程；多图 Stylist 读取当前行程且实际最多选择 9 张照片，图中仅用 3 张作示例。
- 设计图里搜索结果的“用户/游记”等跨模块页签、评论图片/表情、分享图标、收藏分类、发布地点等若未由对应代码证实，只属于图像模型补出的装饰或布局建议，不纳入现有功能承诺；真实搜索范围和评论形式依源码，评论为文字。
- 发布标题上限 100 字、正文 1000 字；以代码为准，设计图可能出现错误示例计数。生成行程配置保留精确数字预算输入，图示预算档位不替代该能力。
- 图中天气逐小时值、地图路径、携宠规则、酒店与地点信息均为示例，不可作为实际服务数据。
- 注册实际只有手机号和密码，不需要验证码；验证码仅用于登录。
- 宠物编辑实际字段为名字、品种、体重；图中的狗头像仅装饰，不代表已有宠物图片上传。
- 个人头像当前以相册选择为准，设计里的拍照选项不能据此当成已有能力。
- 首次完善资料仅头像、昵称、性别、生日；更多字段在编辑资料页。
- 推荐景点可收藏；AI Place 的直接收藏在旧验收文档里存在缺口，本轮不承诺已支持。
- 个性化推荐、笔记可见、位置权限隐私开关需按实际状态与系统权限对齐，界面开关不等同于权限已授予。
- 设置中的存储空间、内容偏好、小组件、未成年人模式、新功能体验、帮助，以及隐私中的账号安全/黑名单、关于中的协议/检查更新，现有实现含 Mock 占位，保留入口并标开发中，不虚构其二级功能。
- 清缓存存在 Mock 行为；不能将图中清理成功提示当成真实磁盘清理能力。
- 天气后段可能有模板兜底，设计数据均为示例；导航为样式示意，真实高德地图/导航 SDK 渲染与功能应保留。
- 新设计中发现页聚合现有推荐、工具入口和 AI 规划；分类位置属于建议，尚未实现。
- 生成成功/失败/后台生成完成、清空行程、取消收藏、删除日记/宠物、移除本机账号、退出登录、加载/空态/权限/网络错误统一采用图示提示组件；文案根据实际动作调整，不意味着新增业务能力。
