# CityGo UI 第一版落地

日期：2026-10-26。依据本次确认的暖白 / 森林绿设计方案，直接更新现有 Android Jetpack Compose App。

## 已完成

- 底栏顺序与命名：发现、行程、地图、社区、我的；登录完成及冷启动进入发现页。
- 全局浅色 / 深色主题、Material 3 容器色、主按钮、标签、卡片和弹窗统一为森林绿体系；消除默认紫色容器和独立黑色资料表单。
- 发现页：城市旅行主视觉（有可用景点照片时使用实图，无图时本地插画）、AI 规划入口、携宠偏好、穿搭工具、附近精选、搜索与原有筛选分页。
- 首页 AI 规划将选中城市传给原全局 ViewModel，进入行程配置弹窗；不绕过原提交与后台生成流程。
- 行程页：概览、天数快捷定位、可展开地点详情、更紧凑的每日添加景点 / 酒店操作、固定 AI 对话入口。同步 / 历史行程 / 地图点位联动 / 原提议确认操作保留。
- 地图：统一周边控件配色与顶部样式，继续使用实际高德 SDK 地图、选线、步骤与导航；未以概念图中的示意地图替换 SDK。
- 社区：标题、搜索、内容来源切换、穿搭入口随瀑布流滚动；保留实际发布、收藏、点赞、评论回复、可见范围与本人内容管理逻辑。
- 穿搭工具选择页：接通原单图 OOTD 与多图结合行程评估两种流程；从发现、社区进入。多图上限仍为 9 张，行程上下文可展开。
- 我的：头像与内容统计、收藏与历史、宠物 / 日记摘要与展开操作。将外观、隐私、缓存、账号、关于统一收拢到设置页。
- 资料编辑、首次完善资料、天气总览与详情适配全局明暗主题；景点详情将相关游记放到内容区，底部保留加入行程和导航，减轻操作拥挤。
- 设置明确标出原有开发中入口；按用户要求移除收货地址入口及其未使用文案资源。
- 穿搭用户页面不再展示后端地址、ADB 转发、Logcat 等联调说明。服务连接方式保持原配置。

## 范围与后续

本轮是可继续迭代的第一版实际界面。设计板中的示例地点、天气、地图路线与装饰控件不是业务数据，不会写入真实行程。设计板是方向参考，并非 56 个示意位全部逐像素复刻：已有功能继续沿原页面 / 弹窗承载，并统一主题和主要布局；真实服务数据、加载和错误状态由原状态流驱动。

后端、数据库、接口字段、账号隔离、AI 生成和导航引擎未因本轮 UI 重设计更换。原设置占位及缓存演示能力仍为原状态，不能将新样式视为功能已完善。

## 建议设备回归顺序

1. 登录 / 注册 / 首次完善资料，然后检查底栏与发现页滚动。
2. 首页携宠偏好 → AI 规划 → 行程配置、生成、历史同步。
3. 行程地点 → 地图 → 路线选择 → 步骤预览 / 实际导航。
4. 单图与多图穿搭上传、流式结果、重试与返回。
5. 社区发布、编辑、可见范围、收藏、评论回复。
6. 个人头像、宠物、日记、收藏、设置、深色模式与账号切换。
