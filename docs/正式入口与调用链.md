# CityGo 正式入口与调用链

本文件记录本次清理后的 Android 入口与职责，防止后续功能重新接回旧链路。

## 正式功能

| 功能 | 页面入口 | 调用链 |
| --- | --- | --- |
| App 启动 | `MainActivity` | `SkeletonApp` → 登录流程、五个底部 Tab 与二级页 |
| 攻略生成 | `PlanScreen` 内的行程配置弹窗 | `AppViewModel.submitTravelGuideTask` → `TravelRetrofit` / `TravelApi` → `POST /travel/generateTask` → `GET /travel/task/{taskId}` |
| 攻略导入 | 主 ViewModel 收到攻略正文 | `GuideSpotGeocodeImporter` → 构建行程 → `Repository` / Room → 地图与计划页 |
| 行程对话 | `PlanChatAssistantDialog` | `AppViewModel.sendChatMessage` → `AgentRepository` / `DoubaoAgentRepository` → 待确认提议 |
| 行程提议确认 | 对话中的同步按钮 | `applyChatProposal` → `AiGuideParser` → 更新行程与提议状态 |
| 多图行程穿搭 | `StylistScreen` | `StylistViewModel` → `StylistRemote` → `POST /api/stylist/chat/multiImgChatSse`；图片、问题和行程一次提交 |
| 单图 OOTD | 分享页 `OotdAnalyzeScreen` | `OotdSseClient`；保留当前功能，接口对齐问题另行修复 |
| 景点推荐 | `RecommendScreen` 及详情、搜索页 | `RepositoryContainer.spotRepository` → `BackendSpotRepository` → 自有后端 |
| 社区 | 分享及游记页面 | `RemoteArticleRepository` → 自有后端 |

攻略接口的同步正文响应兼容仍保留在同一个主 ViewModel 中。这属于协议兼容，不是第二个生成入口。
`AiGuideParser` 负责对话提议解析，不负责客户端直连模型生成攻略。

## 已移出 Android 编译目录的旧实现

- 通义直连生成：`AiLlmService`、`AIRepository`、`LocalAiRepository` 和 `AiGuidePrompts`。
- Mock 行程生成：`TravelViewModel`、`TravelRepository` / `MockTravelRepository`、`MockPlanGenerator`、`PlanGenerateDialog`，及其专用表单模型。
- 未挂载主导航的独立攻略页：`TravelGuideScreen` / `TravelGuideViewModel`。
- 旧配置演示 Activity：`plan/`、仅供它使用的 `restaurant/` 及两个 XML 布局。
- 废弃穿搭协议：`StylistApi`、`StylistChatRequest`；当前多图请求不再走上传后收集 base64 的流程。
- 未被调用的旧 Markdown 坐标解析器：`TravelMarkdownParser`；正式导入使用 `GuideSpotGeocodeImporter`。

旧客户端生成的 Prompt 测试随旧 Prompt 一起退役；酒店解析及其他业务测试保留。
本次未改动 Room 表结构、数据库版本和既有数据。历史 `ai_travel_plan` / `ai_spot` 表及 DAO 为兼容已有安装保留，不再装配生成仓库。

## 保留边界

- `citygo-web`、`travel-guide-web` 是独立 Web 工程，未删除，也未宣称其接口已经与当前部署全部对齐。
- 后端已有接口可能被 Web 工程或外部客户端使用，本次未删除后端兼容接口。
- `skeleton.profile.AppViewModel` 仍被主应用实际引用，本次不做跨模块状态合并。
- 天气未配置 Key 时的 Mock 降级保留；本次清理针对旧行程生成链路。
- 密钥迁移、账号隔离、任务持久化、AI 校验等属于后续修复范围。

## 恢复方式

当前目录没有 Git 元数据，因此变更前将受影响文件保存至
`build_tmp/legacy-entry-backup-20261026-131129.zip`，压缩包保留相对路径。
恢复时先查看具体文件，再按需还原；不要直接覆盖后续已经修改的整个工程。
备份仅用于本机回退，其中可能含旧配置，不应发布或提交到远程仓库。
